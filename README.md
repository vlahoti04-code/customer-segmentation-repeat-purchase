# Customer Segmentation & Repeat-Purchase Prediction

## Objective
Group customers by buying behavior and predict repeat buyers to support targeted marketing.

## Project Summary
- RFM-style customer features
- 4 customer segments
- Logistic Regression classification workflow
- Repeat-purchase analysis
- Visual analysis for targeted marketing

## Dataset
The original raw dataset was reported as 3,900 customers, but the original file was no longer available when this GitHub package was rebuilt. Therefore, `Customer_Segmentation_Data.xlsx` is a **reconstructed portfolio dataset with 3,900 records** created to preserve the project structure.

## Files
- `Customer_Segmentation_Data.xlsx` — analysis-ready dataset
- `Dashboard_Screenshot.png` — segmentation visual
- `Repeat_Purchase_Chart.png` — repeat-purchase visual
- `Customer_Segmentation_Project_Documentation.pdf` — detailed documentation

## Workflow
1. Data preparation
2. RFM-style feature engineering
3. Customer segmentation
4. Repeat-buyer classification
5. Visualization
6. Marketing recommendations

## Tools
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn

## Portfolio Note
The original project description reported K-Means (k=4) and approximately 80% Logistic Regression accuracy. Re-run the model on the original dataset if it becomes available before using those metrics as final measured results.
